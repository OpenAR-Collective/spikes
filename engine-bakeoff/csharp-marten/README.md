# C# on .NET with Marten (champion)

This folder holds the champion side of the [engine bake-off](../README.md): the Wax command path written in C# on the current .NET LTS release, with Marten as the event store on PostgreSQL, the stack [WAX-0025 Primary Programming Language](https://github.com/OpenAR-Collective/platform-design/blob/main/decisions/wax/WAX-0025-primary-programming-language.md) adopts.

Status: not started. This side implements the same workloads as the Python side and keeps every invariant listed in the bake-off README.
