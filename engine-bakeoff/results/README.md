# Results

Each run gets its own folder, named for its date and a short label, for example `2026-10-20-payments-inline/`. The folder holds two things:

- `run.md`, which records the machine, the operating system, the PostgreSQL version and settings, the commit of each side, the workload and worker count, the summary numbers, and whether every correctness gate passed.
- The raw output of the harness, unedited.

A run that fails a correctness gate is recorded too, marked as failed, and does not count toward the result.
